## Sobre esta serie

Laboratorios académicos individuales del curso INF238. El objetivo de documentarlos aquí no es mostrar diseños de nivel empresarial, sino registrar el proceso de diseño, configuración y — sobre todo — diagnóstico de problemas reales de conectividad, que es la parte que más se aprende resolviendo.
